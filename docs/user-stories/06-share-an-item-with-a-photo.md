# Share an item with a photo

Label: icebox

As a member, I need to add an item with its details and a photo so that another neighbor can give it a new home.

## Acceptance criteria
- The form captures name, category, condition, age, location, and description.
- The API accepts optional image uploads up to 5 MB and rejects non-image files.
- New items receive an ID, timestamp, age in years, and an empty comments list.
