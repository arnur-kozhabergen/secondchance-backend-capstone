# View item details and comments

Label: backlog

As a prospective recipient, I need to see an item's description, condition, age, location, and comments so that I can decide whether it is right for me.

## Acceptance criteria
- Each item has a detail page available to signed-in and signed-out visitors.
- The page displays existing comments and a friendly empty state when there are none.
- An unknown item ID returns a clear not-found response.
